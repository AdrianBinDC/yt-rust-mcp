When to use: you have a video id and want the words YouTube already shows in Show transcript, or a caption file for clip times.
When not to use: you need a Data API record, a private caption download, or audio you will transcribe yourself. This tool is experimental, unsupported, and unofficial. It uses an undocumented caption path and can break when YouTube changes. It is not captions.download and it does not use the API key.
Quota: 1 transcript per live fetch, from a local daily cap. A cached repeat costs 0. This does not spend search or non_search.
